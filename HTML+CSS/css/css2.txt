盒子模型

一、 边框 内边距 外边距
    1.边框： border: 1px solid #000; 边框宽度 边框样式(dotted dashed solid) 边框颜色
            border-top/bottom/left/right: 1px solid #000;
            *border-radius: 5px; 边框圆角
    2.内边距： padding: 10px;
            *padding-top/bottom/left/right: 10px;
    3.外边距： margin: 10px;
            *margin-top/bottom/left/right: 10px;
            居中：marign: 0 auto;
            外边距折叠：选小的外边距
            外边距塌陷：给父盒子加上边框或则内边框

二、过渡效果（鼠标经过图片放到，表单获得焦点，输入框变宽）给了一种延迟的效果，而不是瞬间： transition: all 0.5s;

三、尺寸计算：因为padding和margin会改变盒子的尺寸，所以使用：
        box-sizing:border-box; 

四、盒子背景：
        1.背景颜色：background-color: #000; 
        2.背景图片：background-image: url();
        3.背景重复：background-repeat: no-repeat/repeat/repeat-x/repeat-y;
        4.背景位置：background-position: left top center;
        5.背景大小：background-size: cover/contain; 覆盖的时候：会将照片撑满整个盒子 , 包含： 盒子会留一部分空白
        6.背景是否随页面滚动： background-attachment: scroll（滚动）/fixed(固定);

        复合写法：background: #000 url() no-repeat fixed center/cover
        
五、背景渐变：
         background: linear-gradient(to right, red, blue);
         background: radial-gradient(circle, red, blue);
         background-image: linear-gradient(to right, red, blue);

         在对文字渐变的时候，
              /* 渐变背景文字 */
            background-image: linear-gradient(97deg, #0096FF, #BB64FF 42%, #F2416B 74%, #EB7500);
            /* -webkit- 前缀  谷歌浏览器老版本的兼容性写法 */
            -webkit-background-clip: text;
            /* 背景裁剪 以文字的形式裁剪 */
            background-clip: text;
            /* 文本填充颜色 为透明 */
            -webkit-text-fill-color: transparent;

六、盒子阴影： 
/* 盒子阴影: 水平偏移量  垂直偏移量  模糊距离  扩散距离  阴影颜色 */
        box-shadow: 0 0 5px 5px #000;
        transition: all 0.5s;
